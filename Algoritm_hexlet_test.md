### Вопрос №2
Дан код для подсчёта суммы квадратов чисел от 1 до некоторого предела. Выберите все верные утверждения:
def sum_of_squares(limit: int) -> int:
  current = 1
  total = 0
  while current <= limit:
    total = total + current * current
    current = current + 1
  return total

print(result)

Ответ: Функция вернёт значение 14; Переменная total на первой итерации станет равна 1; Если вызвать sum_of_squares(0), функция вернёт 0
